# 🔍 Plagiarism Detection System

## 📌 Project Overview

The **Plagiarism Detection System** is a web-based application designed to identify duplicate or copied content in documents.

The system analyzes submitted content and calculates similarity to help users identify potential plagiarism. It provides a user-friendly interface for performing plagiarism checks and viewing results.

## 🎯 Objectives

- Detect similarities between documents.
- Identify potentially copied content.
- Calculate content similarity.
- Generate plagiarism analysis reports.
- Provide an easy-to-use web interface.

## ⚙️ Requirements

Install the following software before running the project:

- Java JDK
- Node.js and npm
- PostgreSQL
- Maven
- Visual Studio Code or IntelliJ IDEA
- Web browser

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/vm9935581-sys/plagiarism12.git
```

### 2. Open the Project

```bash
cd plagiarism12
```

### 3. Backend Setup

Open the backend folder in your IDE.

Make sure PostgreSQL is installed and configured with the database settings required by the application.

Build and run the Spring Boot application using Maven.

### 4. Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## ▶️ Run the Complete Project

Windows users can use the batch file provided in the repository:

```text
Run_Plagarism_Project.bat
```

## 🗄️ Database

**PostgreSQL** is used to store and manage application data.

## 🔄 How the System Works

1. User opens the plagiarism detection application.
2. User submits content or documents.
3. The backend processes the submitted content.
4. The system performs similarity analysis.
5. The plagiarism result is calculated.
6. The result is displayed on the dashboard.
7. The user can view the generated report.
